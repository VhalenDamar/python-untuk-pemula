# Python untuk Pemula

Repositori catatan dan latihan dasar pemrograman Python.

## Rangkuman Materi
- Variabel & Tipe Data Dasar: latihan angka, teks, dan boolean.
- Operator: latihan operasi aritmatika dan perbandingan dasar.

## Cara Menjalankan Program
1. Masuk ke folder proyek: cd C:\python-untuk-pemula
2. Aktifkan virtual environment: .\venv\Scripts\Activate.ps1
3. Jalankan skrip Python: python nama_berkas.py
